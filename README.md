# Formal Language and Automata Theory Assignments

This repository contains solutions to assignments for the subject "Formal Language and Automata Theory". All solutions are built and tested using the OpenFST library.

## Contents

This project currently includes solutions for the following problems:

* **Q2: Case Conversion:** An FST that converts lowercase letters to uppercase.
* **Q4: Vowel-Consonant Identifier:** An FST that maps vowels to 'v' and consonants to 'c'.
* **Q5: Binary Complement:** An FST that flips binary digits (0 → 1, 1 → 0).

## How to Use

Each solution is contained within its own self-contained folder. To run a solution, navigate into the respective folder and follow the standard OpenFST workflow (compile, compose, print).
